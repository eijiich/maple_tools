Two flame scores appear per column. The 🔥 number is the game's own: the sum of the four line tiers, max 28. Flame score is the flame in main-stat points using your weights, which is what decides whether a roll is actually better — the recording this was built from shows a 23 → 22 roll that gained +60,107 combat power. The reset price, tier tables and line pools are shared with the gear-progression tool, and a test there checks this simulator's rolls average to the exact expected value the ranking computes.
