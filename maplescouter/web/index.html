Send to maplescouter

A page here can't fill another site directly (different origin), so this builds a bookmarklet that does it from within maplescouter.com.

  1. Drag Fill maplescouter to your bookmarks bar — once. It holds no values, so it never goes stale.
  2. Press here.
  3. On maplescouter.com/en/input, click the bookmark. It reads whatever you last copied.

If your browser blocks clipboard reading

Firefox doesn't allow a bookmarklet to read the clipboard, so the one above falls back to asking you to paste. Alternatively use this one-shot link, which has the current values baked in — it needs no clipboard access but must be re-dragged whenever the numbers change.
